# JWT Fullstack Authentication

## Descrizione del progetto
Questo progetto è una web application full stack sviluppata a scopo formativo/dimostrativo, con l’obiettivo di mostrare la realizzazione di un sistema di autenticazione completo basato su JWT (JSON Web Token).

Il backend è sviluppato in Java con Spring Boot, mentre il frontend è realizzato in Angular.  
L’applicazione consente la registrazione e l’autenticazione degli utenti, gestendo l’accesso alle risorse protette tramite token JWT.

## Tecnologie utilizzate

### Backend
- Java
- Spring Boot
- Spring Security
- JWT (JSON Web Token)
- REST API
- JPA / Hibernate
- Database (configurabile)

### Frontend
- Angular
- TypeScript
- HTML / CSS
- HTTP Client

### Altri strumenti
- Git / GitHub

## Funzionalità principali
- Registrazione utente
- Login con generazione di JWT
- Protezione delle API tramite Spring Security
- Gestione dell’autenticazione lato frontend
- Comunicazione frontend-backend tramite REST API

## Struttura del progetto
Il progetto è suddiviso in due parti principali:
- **Backend**: applicazione Spring Boot che espone API REST e gestisce sicurezza e autenticazione
- **Frontend**: applicazione Angular che consuma le API e gestisce l’interfaccia utente

## Obiettivo del progetto
L’obiettivo principale è dimostrare:
- la comprensione del funzionamento di un sistema di autenticazione JWT
- la capacità di sviluppare un’applicazione full stack
- l’utilizzo di tecnologie moderne e largamente impiegate in ambito enterprise

## Stato del progetto
Progetto completato a scopo didattico e in continuo miglioramento.
